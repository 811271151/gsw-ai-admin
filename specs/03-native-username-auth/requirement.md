# 移动端用户名注册登录

## 背景

移动端（Expo Router）现在把邮箱登录、注册表单直接堆在首页底部。本 feature 改为用户名认证，拆出独立的登录、注册屏幕，未登录时首页跳到登录屏幕。

## 需求项

### R-01 注册屏幕 `/register`
字段与校验同 Web（复用 01 的 `signUpSchema`）：用户名、密码、确认密码、邮箱（选填）。键盘「下一项」可在字段间跳转，键盘弹出时不遮挡提交按钮。

验收标准：
- [ ] AC-01 用户名输入 `a-b` 提交 → 显示「用户名只能包含字母、数字和下划线」
- [ ] AC-02 合法输入不填邮箱 → 注册成功，toast「注册成功，请登录」，进入登录屏幕
- [ ] AC-03 用户名已存在 → toast「该用户名已被使用」
- [ ] AC-04 在用户名框按键盘「下一项」→ 焦点移到密码框

### R-02 登录屏幕 `/login`
字段：用户名、密码。提交中显示 Spinner。底部「还没有账户？立即注册」进入注册屏幕。会话 token 由 `@better-auth/expo` 存入 Expo SecureStore。

验收标准：
- [ ] AC-05 正确用户名密码 → 进入首页，首页显示用户名
- [ ] AC-06 错误密码或不存在的用户名 → toast「用户名或密码不正确」
- [ ] AC-07 登录后杀掉 App 再打开 → 仍为登录状态

### R-03 首页鉴权与登出
未登录打开首页（drawer index）时跳到 `/login`。首页显示用户名（不显示占位邮箱）与「退出登录」按钮。登出后清空 React Query 缓存并回到 `/login`。

验收标准：
- [ ] AC-08 未登录启动 App → 显示登录屏幕
- [ ] AC-09 无邮箱注册的账户，首页不出现 `@users.local`
- [ ] AC-10 点击退出登录 → 回到登录屏幕，再次启动 App 仍为未登录

## 依赖
- 依赖 feature：01-username-auth-core
- 外部依赖：server 运行在 `EXPO_PUBLIC_SERVER_URL`，设备能访问该地址

## 非目标
- 移动端「记住我」复选框：App 内会话本就持久保存在 SecureStore，复选框没有对应行为，本期不加
- OAuth 登录
