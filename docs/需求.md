# gsw-ai-admin 需求文档

## 项目背景

gsw-ai-admin 是一个跨平台（Web + Mobile）的管理后台系统，基于 TypeScript monorepo 架构构建，使用 Better Auth 提供统一的身份认证服务。

---

## 功能需求

### 1. 用户认证模块

#### 1.1 用户注册

**功能描述**：允许新用户通过用户名和密码创建账户

**平台支持**：
- Web 端（Next.js）
- Mobile 端（React Native + Expo）

**输入字段**：
- 用户名 (Username)
  - 必填
  - 长度：3-20 个字符
  - 仅支持字母、数字、下划线
  - 唯一性验证（用户名不可重复）
  
- 密码 (Password)
  - 必填
  - 最小长度：6 个字符
  
- 确认密码 (Confirm Password)
  - 必填
  - 必须与密码字段一致

**业务流程**：
1. 用户填写注册表单
2. 前端进行字段格式验证
3. 提交到后端 API
4. 后端验证用户名唯一性
5. 密码使用 Better Auth 内置的安全哈希算法加密
6. 创建用户记录到数据库
7. 返回成功响应
8. 自动跳转到登录页面

**错误处理**：
- 用户名已存在：提示"该用户名已被使用"
- 用户名格式错误：提示"用户名只能包含字母、数字和下划线"
- 密码不符合要求：提示"密码至少需要 6 个字符"
- 网络错误：提示"注册失败，请稍后重试"

**UI/UX 要求**：
- 实时表单验证（输入时显示错误提示）
- 密码可见性切换按钮
- 加载状态（提交时按钮显示 loading）
- 成功提示（Toast/Snackbar）

---

#### 1.2 用户登录

**功能描述**：已注册用户通过用户名和密码登录系统

**平台支持**：
- Web 端（Next.js）
- Mobile 端（React Native + Expo）

**输入字段**：
- 用户名 (Username)
  - 必填
  
- 密码 (Password)
  - 必填
  
- 记住我 (Remember Me) - 可选
  - 勾选后延长会话有效期（30天）
  - 未勾选则会话有效期为 7 天

**业务流程**：
1. 用户填写登录表单
2. 前端进行基本格式验证
3. 提交到后端 API
4. Better Auth 验证凭证
5. 验证成功后创建会话（Session）
6. 返回会话 token
7. 前端存储 token
   - Web: HTTP-only Cookie
   - Mobile: Expo Secure Store
8. 跳转到首页/仪表板

**错误处理**：
- 用户名或密码错误：提示"用户名或密码不正确"
- 账户不存在：提示"该用户名不存在"
- 账户被禁用：提示"账户已被停用，请联系管理员"
- 网络错误：提示"登录失败，请稍后重试"

**安全特性**：
- 登录失败次数限制（5次失败后锁定 15 分钟）
- CSRF 保护
- 会话固定攻击防护

**UI/UX 要求**：
- 表单验证提示
- 密码可见性切换
- 加载状态
- 错误消息显示
- "忘记密码"链接（暂不实现，预留位置）
- "还没有账户？立即注册"链接

---

#### 1.3 用户登出

**功能描述**：已登录用户退出系统，销毁会话

**平台支持**：
- Web 端
- Mobile 端

**业务流程**：
1. 用户点击"退出登录"按钮
2. 调用后端登出 API
3. 服务器端销毁会话
4. 客户端清除本地 token
5. 跳转到登录页面

**UI/UX 要求**：
- 确认对话框（可选）："确定要退出吗？"
- 退出后清除所有缓存数据

---

#### 1.4 会话管理

**功能描述**：自动维护用户登录状态，提供会话检查

**业务逻辑**：
- 会话自动续期：用户活跃时自动刷新 token
- 会话过期检测：token 过期时自动跳转到登录页
- 跨标签页同步：同一浏览器多个标签页登出状态同步（Web）

**Protected Routes（受保护路由）**：
- 未登录用户访问受保护页面时自动跳转到登录页
- 登录后自动跳转回原目标页面

## 技术实现要点

### 数据库设计

**用户表 (User)**：
```prisma
model User {
  id            String    @id @default(cuid())
  username      String    @unique
  name          String?
  image         String?
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
  
  // Better Auth 关联
  sessions      Session[]
  accounts      Account[]
}
```

Better Auth 会自动生成 `Session`、`Account` 等表，通过 `pnpm run auth:generate` 命令生成。

---

### API 端点设计

使用 Better Auth 提供的标准端点：

- `POST /api/auth/sign-up` - 注册（使用 username 字段）
- `POST /api/auth/sign-in/username` - 登录（使用 username 认证）
- `POST /api/auth/sign-out` - 登出
- `GET /api/auth/session` - 获取当前会话

---

### 前端实现

**Web 端 (Next.js)**：
- 使用 Better Auth React hooks
- `useSession()` - 获取会话状态
- `signIn()` - 登录
- `signUp()` - 注册
- `signOut()` - 登出

**Mobile 端 (React Native)**：
- 使用 `@better-auth/expo` 适配器
- Expo Secure Store 存储 token
- Expo Web Browser 处理 OAuth（预留）

---

### 表单验证

使用 `@tanstack/react-form` + `zod` 实现：

```typescript
const signUpSchema = z.object({
  username: z
    .string()
    .min(3, "用户名至少需要 3 个字符")
    .max(20, "用户名不能超过 20 个字符")
    .regex(/^[a-zA-Z0-9_]+$/, "用户名只能包含字母、数字和下划线"),
  password: z
    .string()
    .min(6, "密码至少需要 6 个字符"),
  confirmPassword: z.string(),
}).refine((data) => data.password === data.confirmPassword, {
  message: "两次输入的密码不一致",
  path: ["confirmPassword"],
});

const signInSchema = z.object({
  username: z.string().min(1, "请输入用户名"),
  password: z.string().min(1, "请输入密码"),
});
```

## 页面设计

### Web 端页面

1. **登录页面** (`/login` 或 `/auth/signin`)
   - 用户名输入框
   - 密码输入框
   - 记住我复选框
   - 登录按钮
   - "还没有账户？注册"链接

2. **注册页面** (`/register` 或 `/auth/signup`)
   - 用户名输入框
   - 密码输入框
   - 确认密码输入框
   - 注册按钮
   - "已有账户？登录"链接

3. **首页/仪表板** (`/dashboard` 或 `/`)
   - 显示用户信息（用户名、头像）
   - 退出登录按钮

---

### Mobile 端页面

1. **登录屏幕** (`/login`)
   - 同 Web 端功能
   - 适配移动端键盘

2. **注册屏幕** (`/register`)
   - 同 Web 端功能
   - 适配移动端键盘

3. **首页屏幕** (`/`)
   - 抽屉导航
   - 用户信息展示（用户名、头像）
   - 退出登录选项

## 非功能需求

### 性能要求
- 登录/注册响应时间 < 2 秒
- 表单验证实时响应 < 100ms

### 安全要求
- 密码加密存储（bcrypt/argon2）
- HTTPS 传输
- CSRF Token 验证
- SQL 注入防护（Prisma ORM 自动处理）
- XSS 防护

### 可访问性
- 支持键盘导航
- 表单字段有明确的 label
- 错误信息对屏幕阅读器友好
- 符合 WCAG 2.1 AA 标准

### 响应式设计
- Web 端支持桌面、平板、手机
- Mobile 端适配不同屏幕尺寸（iOS/Android）
